# ParaView CryoPlot Skill
> A skill for Doubao，自动生成ParaView pvpython脚本，冰冻圈遥感科研绘图，AGU期刊标准矢量图

## ✨ Features
- Support NetCDF/VTK/vtu data (Permafrost, Glacier, SAR wave, Cryosphere remote sensing)
- AGU / Nature Geoscience figure style
- Auto generate: bounding box clip, colormap, scale bar(black-white), north arrow, full frame
- Export vector PDF / SVG for journal submission
- Output complete pvpython script + yaml config
